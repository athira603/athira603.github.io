INORWA PRIVACY POLICY

Last Updated: January 2025

1. Introduction & Scope

This Privacy Policy describes how Inorwa ("we," "our," or "us") collects, uses, and protects your personal information when you use our Android mobile application ("App"). This policy applies to all users worldwide and complies with applicable privacy laws including GDPR, CCPA/CPRA, COPPA, and LGPD.

  • Data Controller: Inorwa Development Team
  • Contact: connect@vandrova.com
  • App Package: com.vandrova.inorwa

2. What Personal Data We Collect

2.1 Account & Authentication Data

  • Phone Number (primary identifier)
  • Email Address (optional)
  • Full Name, First Name, Last Name
  • Date of Birth
  • Gender
  • Address (optional)
  • Profile Pictures (stored in Firebase Storage)
  • Authentication Tokens (Firebase Auth)

2.2 User-Generated Content

  • Task Data: Task titles, descriptions, dates, times, completion status
  • Subtask Data: Subtask details and assignments
  • Collaboration Data: Shared tasks and collaborator information
  • User Reports: Content reports and feedback
  • Voice Input: Speech-to-text for task creation (processed locally)

2.3 Device & Technical Information

  • Device Information: Android version, app version, device model
  • App Usage Data: Task completion statistics, streaks, achievements
  • Network Information: Internet connectivity status
  • App Preferences: Settings, themes, notification preferences
  • Installation Data: App install referrer information

2.4 Contact Information

  • Device Contacts: Read for collaborator suggestions (with permission)
  • Contact Names & Phone Numbers (for task collaboration features)

2.5 Financial & Transaction Data

  • Payment Information: UPI transaction references, amounts, payment status
  • Subscription Data: Membership levels, payment history
  • Referral Codes: User referral codes and commission tracking

2.6 Analytics & Performance Data

  • App Performance: Crash logs, error reports
  • Usage Analytics: Feature usage, task completion patterns
  • Device Performance: App responsiveness, battery usage

2.7 Android Permissions

Our app requests the following Android permissions to provide full functionality:

  • RECORD_AUDIO: Enables voice input and speech-to-text features for task creation
  • READ_CONTACTS: Allows contact suggestions for task collaboration and sharing
  • WRITE_EXTERNAL_STORAGE: Enables local data backup and file storage functionality
  • READ_EXTERNAL_STORAGE: Allows importing and exporting of task data and files
  • INTERNET: Required for data synchronization, cloud backup, and online features
  • ACCESS_NETWORK_STATE: Monitors network connectivity status for optimal app performance
  • VIBRATE: Provides haptic feedback for notifications and task reminders
  • WAKE_LOCK: Enables background processing for task synchronization and notifications
  • CAMERA: Allows users to capture and set profile pictures
  • ACCESS_FINE_LOCATION: Enables location-based features and contextual task management

Permission Control: You can manage these permissions through your device's Settings > Apps > Inorwa > Permissions. Disabling certain permissions may limit app functionality.

8. Data Retention

8.1 Retention Periods

  • Account Data: Until account deletion or 3 years of inactivity

  • Contact Data: Until permission revoked

8.2 Deletion Rights

Users can request data deletion through app settings or by contacting us.

9.1 GDPR Rights (EU/EEA Users)

  • Access: Request copies of your data
  • Rectification: Correct inaccurate data
  • Erasure: Request data deletion

  • Restriction: Limit data processing
  • Objection: Object to certain processing
  • Withdraw Consent: Revoke consent at any time

9.2 CCPA/CPRA Rights (California Users)

  • Delete: Request deletion of personal information
  • Opt-Out: Opt-out of sale/sharing (we don't sell data)
  • Non-Discrimination: Equal service regardless of privacy choices

9.3 LGPD Rights (Brazilian Users)

  • Confirmation: Confirm data processing
  • Access: Access your data
  • Correction: Correct incomplete data
  • Anonymization/Deletion: Request data deletion
  • Portability: Data portability
  • Information: Information about data sharing

10. Children's Privacy (COPPA/GDPR-K)

  • Age Requirement: Users must be 13+ to create accounts
